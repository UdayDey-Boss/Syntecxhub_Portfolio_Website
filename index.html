01 — About

I started with a single HTML file and a lot of curiosity about why things moved when I hovered them.

Two years later that curiosity turned into a habit: pick something on the web I like, take it apart, rebuild it from scratch, then figure out what I would have done differently. Most of what I know about layout, accessibility and CSS came out of that loop.

Right now I care most about the unglamorous parts — keyboard focus that stays visible, text that survives a 320 px screen, and CSS that the next person can read without a map. If a page needs a framework to show three sections, I would rather not use one.
